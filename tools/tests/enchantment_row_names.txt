# Every enchantment row name, pinned so that a reword cannot rename one in
# silence. `test_a_reword_must_not_rename_a_row.py` beside this file compares
# the two generated enchantment tables against this list.
#
# WHY A SEPARATE FILE RATHER THAN THE TABLES THEMSELVES. A row name is built
# from the FIRST 48 CHARACTERS of the enchantment's sentence, and
# `FCataclysmRolledEnchantment` stores that name on a dropped item, so a
# renamed row is orphaned on every saved item carrying it. The name already
# lives in `game/Data/Enchantments*.csv`, and it changed there SIXTEEN times
# without anything complaining, because the generator rewrites those files
# automatically and nothing compared them to anything. This file is not
# generated. Updating it is a human act, which is the whole point.
#
# TO CHANGE IT: if a row was renamed, say so out loud -- the saved items
# carrying the old name will find nothing. Issue #1799 carries that question
# to the project owner. If an enchantment was genuinely added, add its line.
#
# Sorted, so a diff is readable. Negative and positive together.
